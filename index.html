Время и экономия пока не замерены. Точность проверяется по исходному документу; для сканов применяется OCR.

Как устроена текущая версия

Приложение обрабатывает документы локально, без подключённой нейросети. Находит поля по заданным правилам, позволяет открыть исходник и подсвечивает фрагменты, из которых взяты значения. Поддерживает ручную проверку и выгрузку таблицы и реестров в Excel/Word.

Сканы распознаются через OCR при установленном Tesseract. Надёжность на наборе примерно из 500 документов ещё предстоит проверить; процент точности и экономию времени пока не заявляю.
